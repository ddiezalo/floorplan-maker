How to use

  1. Measure the walls in order. Choose how many walls there are, select clockwise or counter-clockwise, then enter each length.
  2. Add clues if you have them. Enter diagonals and any corners you are confident are 90°. They help define irregular rooms.
  3. Generate the shape. The tool finds a compatible geometry, allowing small measurement errors within your selected tolerances.
  4. Add more rooms and combine them if needed. Choose how two rooms connect, then select the matching walls and corners. Your selection is highlighted in green on each room preview.

Tip: Start with the recommended tolerances. Increase one only when that measurement is uncertain or if the calculation fails.
